## 2. Deviations / judgement calls (for Design.md §11 at reconcile)

1. **Long insight quotes → Fraunces, not Caveat.** §3.4 caps a `data-hand="quote"` at 240 chars; three sourced quotes in `data/projects.ts` are 263 / 325 / 380 chars. D7 forbids trimming data, so `InsightCard` renders a quote over the limit verbatim in Fraunces (`.artifact-quote-long`) **without** `data-hand` — content, so EVAL-018 rule 5 never sees it and `Hand`'s render guard never throws. Unit-tested.
2. **Contrast corrections (Design §2.1 "fix the colour, not the number"):** evaluation `dt` labels **forest** instead of the mockup's steel (steel/paper-2 = 3.59:1); structural kind badge **navy-2** (steel/ivory = 4.13:1 at 11 px); text on the kraft doc tag **navy** (terracotta/kraft = 4.16:1 — the §2.1 correction); the thinking-node source link stays the mockup's **rust**. Fable 5.1 had switched it to terracotta after the first gate's axe reported `#bc5838` at 4.07:1. Opus 5.5 found that reading was a **mid-fade blend** (the node was still fading in; the other hits on that run were 1.35–1.46:1, also partial opacity). Rust at rest is `#b64927`, which is 4.71:1 on paper at 13 px/600. The axe test now waits for all 8 nodes to reach opacity 1, and it passes at 390 and 1440 with rust. Self-reported badge is terracotta (7.0:1), measured is forest (8.7:1). 
3. **Medallion numerals are 1–8 (mockup), `aria-hidden`, plain Caveat** — not `Hand label` (a 1-digit numeral would fail the §3.4 "2-digit numeral" rule and the `ol` already numbers the nodes for AT). Chapter-nav and chapter numerals are `Hand label` "01"…"08" as §7.3 says; they sit outside a `data-paper` object, which §7.3 sanctions explicitly for these two places (the collector only checks `p/h*/li/td/th/dt/dd`, so no hit either way).
4. **Chapter-nav rows are 44 px** (mockup 24 px + 9 px gap) — EVAL-008 target floor beats the mockup density.
5. **The label-tag pin is a CSS pseudo-element**, not a `Pin` fastener (a `Pin` must be a direct child of a `Sheet`; making every stage label a `Sheet tag` would fight the kraft/uppercase tag typography for no gain). Not counted either way.
