## Judgement calls (plan/Design precedence, orchestrator delegated)
1. **Scene:** I did not rebuild §7.7's wide masked scene, because TKT-95's `SceneOpener` already shows it (EXE-18 / Dev-24). I kept the caption chip as the opener's third decoration so the count matches §3.3 (3). This is the same approach as TKT-80's WorkHero.
2. **Rotations:** §7.7 gives Tegaki −2.2° and Cinematic Portfolio +1.1°. `Sheet` clamps both to the normative §3.1 cap (±0.9°), and I did not override the cap.
3. **Poke arrow:** the plan says `arrow="down"`. I used `arrow="right"`, because `sketch-paths.ts` records that arrow as the playground mockup's drawing.
4. **Wide card at ≤ 640:** it keeps two fastener tapes in the DOM. CSS centres the left tape and hides the right one ("one centre tape ≤ 640") so the host never has 3 fasteners.
5. **Tegaki numeral colour:** navy-2, not the mockup's terracotta. Terracotta on kraft measured 4.15:1 in axe, which fails AA (same issue as Dev-13).
6. **Eyebrows:** they use `--text-caption` (14 px), not the mockup's 12 px, to meet the EVAL-008 14 px floor.
