## What shipped

- **`/certifications`** (static, `buildMetadata`, OG card `app/certifications/opengraph-image.tsx`,
  sitemap + `routes.json` + EVAL-017 route list). Nav: one line in `lib/nav.ts` —
  `{ label: "Certifications", href: "/certifications" }`.
- **Timeline** (`components/certifications/CertificationTimeline.tsx`): the five certifications in
  the reference, newest first — tinted year tape (blue/yellow are the generated washi tapes), round
  deckled badge (the Credly badge artwork), rail dot, torn tinted card (name `h2`, issuer with a
  building icon, rule, skills), pinned sticky note with doodle; torn title strip, Caveat aside +
  mountain, footer books LEARN/BUILD/APPLY/GROW + paper plane + "Continuous learning for higher
  impact." strip.
- **More on Credly** (`MoreCredentials.tsx`): the other 17 Credly badges as paper tiles, in two
  shelves (Certifications · 10, Skill badges · 7).
- **Interaction (spec)**: each certification is ONE `<a href={credentialUrl} target="_blank"
  rel="noopener noreferrer" aria-label="View <name> credential on Credly">` wrapping the whole
  artifact; no Verify button; always-visible Caveat "View credential ↗" (terracotta, secondary);
  hover/focus = −4 px lift, −0.6° rotate, deeper shadow, ↗ nudge + corner ↗ cue; reduced motion =
  shadow only (no transform, no transition); rust 2 px focus ring; ≥ 44 px; `aria-describedby`
  carries issuer / skills / sticky text.
- **Analytics**: `CredentialLink` (the only client component) calls `track("Certification
  Credential Clicked", { certification_name, issuer, certification_year, credential_provider:
  "Credly", credential_url, page: "portfolio", section: "certifications" })` from
  `@vercel/analytics` in `onClick`, inside try/catch, never `preventDefault`.
- **Data**: `data/certifications.ts` — one array (22), newest first, `.map()`-rendered.
  `name/issuer/year/issued/expires/badge/credentialUrl` from Credly `badges.json`; `skills` +
  `applied` for the five reference certs are Tushar's copy (commented); others carry a verbatim
  subset of Credly's skills and `applied: null` (no sticky note).
- **Badges**: `public/media/certifications/*.webp` (240 px, 3.8–12 kB each) + README with sources.
- **Collage pieces** (orchestrator update): cropped from the Tushar-approved Higgsfield sprite sheets
  → `public/media/illustrations/collage-{scrap-sage,scrap-kraft,leaf-1,fern,washi-blue,washi-yellow}.webp`
  (≤ 24 kB each), provenance rows in `content/media/illustrations/README.md`.
