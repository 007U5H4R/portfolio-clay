==================================================
221. TROUBLESHOOTING
==================================================

### Divider looks like zig-zag

Cause:
geometry too regular.

Fix:
use generated irregular torn ridge assets and softer contours.

### Divider looks flat

Cause:
layers touch with no shadow separation.

Fix:
add subtle vertical spacing, edge thickness, and close-contact shadows.

### Divider looks like mountains rather than torn paper

Cause:
scenic silhouette too literal.

Fix:
increase paper fiber/tear cues and reduce sharp mountain peaks.

### Divider causes horizontal scrollbar

Cause:
parallax layer wider than clipped container.

Fix:
ensure divider has `overflow: hidden/clip`, position layers absolutely, and keep expansion modest.

### Divider jumps during scroll

Cause:
scroll calculations causing React rerenders.

Fix:
use RAF + refs / motion values instead of component state.

### Mobile feels janky

Cause:
too many layers/assets.

Fix:
reduce to 3 static/lightly moving layers.

### Paper texture looks blurry

Cause:
source resolution too low.

Fix:
generate/export wider source while maintaining optimized WebP.

### White rectangle appears

Cause:
asset transparency failed.

Fix:
regenerate or correctly preserve alpha.

### Parallax feels gimmicky

Cause:
travel distance too high.

Fix:
cut movement roughly in half.

### Divider competes with section headings

Cause:
height/contrast/decorations too strong.

Fix:
reduce visual weight.

233. GLOBAL 3D DEPTH SYSTEM — ALL PAPER UI AND IMAGES
==================================================

Extend the entire paper-cut design system so that every meaningful paper UI element and every 3D paper-cut image scene has a consistent, believable physical depth model.

This is a global design-system requirement, not a one-off shadow effect.

The portfolio should feel constructed from stacked handmade paper, cut cardstock, raised labels, layered illustrations, mounted artwork, pinned notes, paper photographs, and shallow shadow-box scenes.

CORE PRINCIPLE:

> Every important paper element should appear to occupy a believable physical layer in space.

Do NOT add generic CSS box-shadow to everything.

Depth should come from a combination of:

1. layer hierarchy
2. paper thickness
3. contact shadow
4. ambient shadow
5. edge separation
6. subtle elevation
7. intentional overlap
8. controlled rotation
9. material texture
10. optional parallax for selected scenes

The result must remain editorial, handcrafted and tactile — never generic SaaS, glassmorphism, neumorphism, plastic 3D or glowing UI.

==================================================
234. GLOBAL DEPTH SCALE
==================================================

Create shared depth tokens. Use the existing design-token system where available.

DEPTH 0 — FLAT PAPER
Page/background surfaces.

DEPTH 1 — EMBOSSED
Subtle raised printed detail.

DEPTH 2 — RESTING
Normal paper cards and notes.

DEPTH 3 — RAISED
Featured cards and mounted images.

DEPTH 4 — FLOATING
Hero artwork and important focal interactions.

DEPTH 5 — FOREGROUND
Focal decorative objects and foreground scene elements.

Conceptual starting shadows:

```css
:root {

  --paper-shadow-3: 0 6px 10px rgba(38, 27, 18, 0.13), 0 2px 3px rgba(38, 27, 18, 0.08);
```

Tune against the current portfolio rather than blindly copying these values.

==================================================
235. CONTACT + AMBIENT SHADOWS
==================================================

Where appropriate combine:

CONTACT SHADOW — small, close, relatively dark.

AMBIENT SHADOW — larger, softer, lower opacity.

The contact shadow says “this paper touches the surface.”
The ambient shadow says “this paper is elevated.”

Avoid giant diffuse shadows.

==================================================
236. PAPER THICKNESS
==================================================

Important paper elements should have a visible sense of thickness.

Use one or more of:

- pseudo-element underlay
- offset duplicate paper layer
- darker paper backing
- thin kraft/terracotta backing sheet
- subtle darker torn edge

Example:

```css
.paper-card::after {
  content: "";
  position: absolute;
  inset: 2px -2px -3px 2px;
  z-index: -1;
  background: var(--paper-underlay);
  clip-path: inherit;
}
```

Do not add thickness to every tiny label.

==================================================

Use overlap as a primary depth cue.

- photograph overlaps note
- note overlaps background

- illustration overlaps landscape

==================================================
239. CONTROLLED ROTATION
==================================================

Use tiny rotations for physical imperfection:

-0.5deg
+0.5deg
+1deg
-1.2deg

Maximum for ordinary UI: approximately ±2deg.

Hero collage artwork may use slightly more. Never rotate critical navigation/control text enough to reduce readability.

==================================================
240. INTERACTIVE PAPER DEPTH
==================================================

Interactive paper elements may respond physically.

Rest: normal elevation.
Hover: lift approximately 2–4px and slightly strengthen shadow.
Pressed: compress toward the paper surface.

Example:

```css
.paper-interactive {
  transform: translateY(0);
  transition: transform 180ms ease, box-shadow 180ms ease;
}
.paper-interactive:hover {
  transform: translateY(-3px);
}
.paper-interactive:active {
  transform: translateY(1px);
}
```

Do not combine large scale + rotation + translation. Choose one dominant physical response.
