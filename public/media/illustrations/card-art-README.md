# Card art provenance (TASK-202)

3D paper-cut art for the 13 `/projects` covers and the three home Featured Work cards. Generated with the Higgsfield connector, model `gpt_image_2_5`, quality `medium`, resolution `1k`, 0.5 credit per image (measured). Masters (PNG, 1344 px wide; 1024 px for the 3:2 RailCite layers) are kept outside the repo in `/Volumes/E Drive/Dev/.scratch/card-art/raw/`; `scripts/card-art/encode.mjs` turns them into the shipped files.
